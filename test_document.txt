Welcome to SOLVENT_KMP - Test Document

This is a test document to demonstrate how the file analyzer works.

ABOUT THE SYSTEM:
The SOLVENT_KMP application is a rule-based document analyzer that can process multiple file formats including:
- Text files (.txt)
- PDF documents (.pdf)
- Word documents (.docx)
- Video files (.mp4, .mkv, .mov, .avi, .flv, .webm)

FEATURES:
1. Keyword Extraction: The system extracts important keywords from your questions
2. Document Parsing: Automatically reads and extracts text from various document formats
3. Video Audio Extraction: Converts video audio to text using speech recognition
4. Relevance Scoring: Calculates how relevant each document section is to your question
5. Confidence Metrics: Shows how confident the system is in its answers

HOW TO USE:
1. Place your documents in the /documents folder
2. Start the Flask application
3. Open http://localhost:5000 in your browser
4. Type your question in the chat box
5. The system will search through all documents and return the most relevant answer

SUPPORTED FILE TYPES:
- TXT: Plain text files
- PDF: Adobe PDF documents (requires pypdf library)
- DOCX: Microsoft Word documents (requires python-docx library)
- MP4, MKV, MOV, AVI, FLV, WEBM: Video files (extracts and transcribes audio)

TECHNOLOGY STACK:
- Backend: Flask (Python web framework)
- Frontend: HTML5, CSS3, JavaScript
- Text Processing: Regular expressions, natural language processing
- Video Processing: MoviePy for audio extraction, SpeechRecognition for transcription

TIPS FOR BEST RESULTS:
- Use specific, clear keywords in your questions
- Ask one question at a time
- Provide context in your questions
- Ensure your documents contain relevant content
- For videos, make sure they have an audio track that can be transcribed

This application is designed to be lightweight and doesn't require any AI models or external APIs beyond Google's free speech recognition service.
